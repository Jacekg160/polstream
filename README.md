# PolStream 0.3.0 – Render

Ta wersja jest przygotowana pod publiczne wdrożenie na Render.

## Funkcje
- filmy
- seriale
- wyszukiwanie
- polskie tytuły i opisy z TMDB, gdy są dostępne
- plakaty i tła
- szczegóły filmów
- sezony i odcinki seriali

## Jeszcze nie ma
Źródeł odtwarzania ani napisów. Dodamy je w kolejnym etapie z legalnych/autoryzowanych źródeł.

## Render
Build Command: npm install
Start Command: npm start

Environment Variable:
TMDB_TOKEN = Twój TMDB API Read Access Token

Po wdrożeniu:
https://TWOJA-USLUGA.onrender.com/manifest.json

PolStream korzysta z TMDB API. Należy przestrzegać zasad TMDB dotyczących API i atrybucji.
